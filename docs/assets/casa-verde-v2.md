# Casa Verde: landing experimental /v2

## Dirección
Landing inmobiliaria de arquitectura inspirada en la referencia adjunta: paisaje, título monumental y arquitectura en primer plano. Diseño original con casa brasileña, verdes naturales, neutrales mate y acento naranja. DESIGN_VARIANCE: 7; MOTION_INTENSITY: 7; VISUAL_DENSITY: 3. CSS Modules, fuentes locales Clash Grotesk / General Sans y framer-motion ya instalado.

## Assets
Generados con la herramienta integrada de ImageGen. No se aumentó artificialmente su resolución.
- casa-verde-scene.png / .webp: fotografía original, 1672 × 941.
- casa-verde-background.png / casa-verde-background-clean-v1.webp: paisaje completado sin construcción, 1672 × 941.
- casa-verde-foreground.png / .webp: recorte con alpha real de arquitectura, jardín y terreno, 1671 × 941.
Los PNG son las fuentes y WebP son las versiones consumidas. El recorte se exportó sin pérdida para conservar el alpha.
Las dos capas comparten object-fit, object-position, escala inicial y origen de transformación. Hay un píxel de diferencia en el ancho nativo generado; la revisión visual no mostró bordes desalineados.

## Implementación
Ruta: app/[locale]/(experimental)/v2/page.tsx. No utiliza el layout (public); conserva la raíz con idioma. Prototipo editorial en español, sin datos de Supabase.
Componente y CSS: features/experimental-v2/.
Fondo: desplazamiento 0 → 145 px. Título: 0 → 235 px. Primer plano: 0 → -35 px y escala 1.035 → 1.075. El avance está vinculado al tramo visible del hero mediante useScroll, sin fijar la página ni interceptar el scroll.
prefers-reduced-motion conserva la composición estática. Modo oscuro fijo, independiente del tema del sistema. Hero a sangre, sin marco ni esquinas redondeadas. La vegetación del recorte existente se funde mediante un degradado con la superficie verde profunda (#101b16) de las secciones siguientes; se complementa con una cuarta capa transparente de palmeras y filodendros, que cruza el límite de las secciones y se desplaza de 0 a -60 px. La base se desvanece mediante una máscara CSS; las hojas quedan sobre el fundido y debajo de los controles. Respeta prefers-reduced-motion. Metadatos noindex/nofollow para el prototipo.
La propiedad y las imágenes son ficticias y están identificadas como demostración en el footer.
No se modificaron la home, el proxy, los mensajes existentes ni lib/brand.ts (tenía cambios previos del usuario).
